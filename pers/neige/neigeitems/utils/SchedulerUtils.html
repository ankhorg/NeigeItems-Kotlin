Package pers.neige.neigeitems.utils

Class SchedulerUtils

  • All Implemented Interfaces:
    
public class SchedulerUtils

    Bukkit/Paper/Folia scheduler compatibility layer.

    Folia does not have one main thread. Calls that belong to an entity are therefore routed through that entity's scheduler; calls without an entity are routed through Folia's global-region scheduler.
